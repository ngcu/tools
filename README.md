# OmniTools (오프라인 지원 올인원 이미지 & 문서 스튜디오)

> **포토샵 스타일 이미지 정밀 편집, 오피스 & PDF 이미지 변환, 다중 이미지/엑셀 병합, 찬양/음악 타이머 웹 도구**  
> 모든 작업은 서버로 파일을 전송하지 않고 사용자의 브라우저 로컬 캔버스 및 WASM 환경에서 100% 안전하게 처리됩니다.

---

## 📌 주요 도구 목록

1. **Auto Crop & Manual Crop (스마트 이미지 자르기)**
   * 배경색 자동 감지 기반 외곽 여백 한 번에 자르기 (Auto Crop)
   * 8방향 리사이즈 핸들 및 자유/1:1/4:3/16:9 비율 고정 수동 크롭
   * PNG, JPG, WebP 고화질 내보내기 및 클립보드 복사

2. **Image Edit Studio (이미지 정밀 편집)**
   * **자르기 (Crop)**: Auto Crop 여백 감도 조절 및 즉각 자르기, 원본 리셋
   * **이미지 크기 (Resize)**: 원본 비율 유지/해제 및 % 배율(20%~200%) 원클릭 리사이즈
   * **캔버스 크기 (Canvas Size)**: 9방향 앵커 포인트 기반 캔버스 확장/축소 및 투명/색상 여백 채우기
   * **회전 / 반전 (Rotate & Flip)**: 90° 회전, 좌우/상하 반전, 0.1° 단위 정밀 회전, 1px 초정밀 가로/세로 기준선
   * **배경색 조정 (Background Color)**: 전체 영역 동일 색상 제거 및 외곽 연결 영역 투명화/색상 대체, 화면 스포이트 기능
   * **색상 보정 (Color Adjustment)**: 밝기, 대비, 채도 실시간 조절
   * **톤 커브 (Tone Curves)**: 포토샵 스타일 5포인트 Catmull-Rom 곡선 (블랙/암부/중간톤/명부/화이트), S-Curve 대비강화 프리셋
   * **선명도 / 블러 (Sharpen & Blur)**:
     - 고주파 언샵 마스크 선명도 조절
     - **텍스트/선 굵게 (자연스러운 볼드 효과)**: 얇은 글자나 선을 1~2px 자연스럽게 두껍고 진하게 보강하는 모폴로지 필터
     - 화면 드래그 타일링(모자이크) 및 가우시안 블러 영역 가림
   * **텍스트 레이어 시스템 (Text Layer)**:
     - 복수 텍스트 객체 자유 추가 (`[+ 텍스트 추가]`)
     - 각 텍스트 객체 드래그 이동 및 더블클릭/더블터치 재수정
     - 뷰포트 배율과 1:1 동기화 (화면 크기와 저장 크기 100% 일치)
     - 기본 투명도 100%
     - 텍스트/배경/테두리 색상 화면 스포이트(EyeDropper) 지원
     - 배경 색상 간편 체크박스 토글
     - 테두리 색상 기본 노출 및 3종 선 스타일 지원 (실선, 점선, 둥근 점)
   * **외곽 효과 (Border & Radius)**: 모서리 둥글게, 외곽 테두리 두께 및 색상

3. **File to Image Converter (오피스 문서 변환)**
   * Word(.docx), PowerPoint(.pptx) 문서를 브라우저 로컬에서 고화질 PNG/JPG 이미지로 렌더링 및 ZIP 압축 다운로드

4. **PDF to Image Converter (PDF 변환)**
   * PDF 문서의 모든 페이지를 지정한 DPI/배율로 이미지 변환 및 개별/일괄 다운로드

5. **Image Merge Studio (다중 이미지 병합)**
   * 수직/수평/격자 배열 병합, 여백 및 배경색 지정

6. **Excel Merge Studio (엑셀 데이터 병합)**
   * 여러 개의 엑셀(.xlsx, .xls) 및 CSV 파일을 하나의 통합 시트로 고속 병합

7. **Music / Worship Timer (찬양 & 음악 타이머)**
   * 발표, 예배, 연습용 직관적인 카운트다운 타이머 및 사운드 알림

## 🚀 최근 주요 업데이트 내역

### 1. 공통 UI 및 텍스트 시인성 대폭 개선
* Auto Crop 여백 감도 라벨 및 % 수치, 상하좌우 트리밍 픽셀, 크롭 뱃지 텍스트를 **2단계 확대**하여 가독성을 높였습니다.
* 좌하단 캔버스 해상도 표시 및 새 이미지 교체 단축키 안내 텍스트를 **2단계 확대**하였습니다.
* 도구 팔레트 헤더 라벨을 **2단계**, 도구 선택 버튼 텍스트를 **1단계 확대**하고 팔레트 너비를 확장하여 텍스트 잘림 현상을 방지하였습니다.
* 뷰포트 이미지 영역의 실측 픽셀 치수 텍스트를 **2단계 확대**하였습니다.
* 중앙 하단 zoom % 및 화면 맞춤 버튼 텍스트를 **2단계 확대**하였으며, **화면 맞춤 시 실제 축소 배율(예: 38%)이 정확히 표시**되고 **100% 버튼 클릭 시 1:1 실제 원본 픽셀 크기(100%)로 정확히 전환**되도록 계산 로직을 정상화하였습니다.

### 2. [자르기] 불필요한 적용 버튼 단일화
* 자르기 패널 하단의 중복된 "자르기 적용" 버튼을 제거하고, 상단 공통 "변경 적용" 버튼으로 흐름을 단일화하였습니다.

### 3. [캔버스 크기] 앵커 UI 정밀도 향상
* 9개 앵커 박스에서 선택된 박스의 가운데 점(`●`) 및 기본 점(`•`)을 제거하여 깔끔한 레이아웃을 구현하였습니다.
* 대각선 화살표 대비 작게 보이던 상하좌우 화살표(`↑`, `↓`, `←`, `→`) 크기를 **2단계 확대**하여 대각선과 완벽한 시각적 균형을 맞췄습니다.

### 4. [회전 / 반전] 기준선 스타일 및 기본값 정비
* 가로/세로 기준선 두께를 얇은 **1px 단선**으로 변경하고, 주변의 형광 번짐(Glow/Shadow) 효과를 완전 제거하였습니다.
* 작업 편의를 위해 기준선 및 격자망의 초기 기본값을 **꺼짐(false)** 으로 변경하였습니다.

### 5. [배경색 조절] 스포이트 및 직관적 우선순위
* 제거할 대상 색상 및 대체 색상 선택란에 **스포이트(EyeDropper) 아이콘**을 추가하여 화면의 픽셀 색상을 클릭 한 번으로 가져올 수 있도록 개선하였습니다.
* 적용 범위 순서를 **1순위: 전체 영역 동일 색상 제거**, **2순위: 외곽 연결 배경만**으로 변경하고 `(권장)` 문구를 제거하였습니다.
* 패널 하단의 중복된 "배경 투명화 적용" 버튼을 제거하였습니다.

### 6. [톤 커브] Catmull-Rom 곡선 알고리즘 수정 (버그 해결)
* 제어점 사전 clamp로 인해 음수 블랙(-25 등)과 255 초과 화이트(+20 등)가 적용되지 않던 문제를 해결하였습니다.
* 가상 제어점 스플라인 계산 후 256개 LUT 최종 매핑 시점에 클램프하도록 수정하여, 깊은 블랙(암부 압축)과 눈부신 화이트 및 S-Curve 대비강화 효과가 즉각적으로 시각화 및 적용됩니다.

### 7. [선명도 / 블러] 메뉴 통합 및 텍스트 굵게 필터 추가
* 도구 팔레트에서 기존 `선명도`와 `타일링/블러`를 **`선명도 / 블러`** 도구 하나로 통합하였습니다.
* **텍스트 / 선 굵게 (자연스러운 볼드 효과)**: 얇은 글자나 도면 선을 1~2px 자연스럽게 볼드화하여 가독성을 높여주는 3x3 모폴로지 필터를 추가하였습니다.
* 패널 내에서 [선명도 조절], [텍스트/선 굵게], [타일링/블러 영역 가림]을 한곳에서 편리하게 작업할 수 있습니다.

### 8. [텍스트] 객체 기반 텍스트 레이어 시스템 전면 개편
* **자동 생성 및 강제 베이킹 제거**: 도구 진입 시 텍스트가 자동 생성되지 않으며, **`[+ 텍스트 추가]`** 버튼을 눌러야 텍스트 객체가 생성됩니다. 다른 도구로 이동해도 강제 베이킹되지 않고 유지됩니다.
* **저장 시 확대 버그 해결**: 뷰포트 배율(`scale`)을 폰트 및 박스 스타일에 정확히 연동하여, **편집 화면에서 보이는 크기와 최종 저장/내보내기 크기가 100% 동일**합니다.
* **객체 이동 및 더블클릭 수정**: 여러 개의 텍스트 객체를 생성할 수 있으며, 화면에서 드래그하여 이동하고 더블클릭(더블터치)하여 언제든 내용과 스타일을 다시 편집할 수 있습니다.
* **스타일 & 스포이트**:
  - 기본 투명도 **100%**
  - 텍스트 색상, 배경 색상, 테두리 색상 모두 **스포이트 버튼** 지원
  - 테두리 색상 컨트롤이 배경 색상 바로 아래에 기본 노출
  - 배경 색상 라벨 바로 우측에 **체크박스 토글** 배치
  - 테두리 선 스타일 3종 지원 (**실선 Solid**, **점선 Dashed**, **둥근 점 Dotted**)

## ⚖️ 폰트 웹 사용 및 저작권 가이드

OmniTools는 사용자의 법적 안전과 웹 표준을 최우선으로 고려하여 폰트 시스템을 구성하였습니다:

1. **Noto Sans KR (구글 본고딕)**:
   * **라이선스**: SIL Open Font License (OFL 1.1)
   * **사용 범위**: 개인 및 기업, 영리/비영리 목적의 모든 상업적 웹사이트에서 무료 임베딩 및 인쇄, 변형 사용이 전면 허용됩니다.

2. **나눔고딕 / 나눔명조**:
   * **라이선스**: 네이버 Open Font License (OFL)
   * **사용 범위**: 상업적/비상업적 무료 이용이 가능합니다.

3. **맑은 고딕, Apple SD 산돌고딕 Neo, 바탕체, Arial, Impact 등**:
   * **방식**: 웹 서버에 폰트 파일(.ttf/.woff)을 무단 복제하여 배포하는 방식이 아니라, 방문자의 기기(Windows, macOS, iOS)에 이미 정품으로 설치된 OS 내장 시스템 글꼴을 CSS `font-family`로 호출하여 캔버스에 렌더링합니다.
   * **라이선스 검토 결과**: 시스템 폰트 호출 방식은 폰트 파일 재배포에 해당하지 않으므로 저작권 분쟁 소지가 전혀 없습니다.
